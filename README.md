# The Guardian Growth Audit

**Live → https://eddieatadapty.github.io/guardian-flow-rebuild-v2/**

Five ideas to turn more The Guardian users into subscribers, each built into a clickable version of The Guardian's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Spot web supporters, register everyone else | +10–20% registrations, and no paywall for existing supporters |
| 02 | Tell the story behind the topic they pick | +5–15% CR to purchase |
| 03 | Ask on day one, in the reader’s words | +10–20% CR to purchase |
| 04 | One paywall per edition | +5–10% CR to purchase, ARPU +5–10% |
| 05 | Give closers a second chance | +10–15% ARPU |

Every price, rating and feature comes from The Guardian's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for the Guardian. Benchmarks are cross-category: there’s no news category in the report. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
